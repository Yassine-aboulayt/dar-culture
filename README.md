# Dar Culture

Livrable B2

Site d’une association culturelle marocaine, réalisé avec HTML, CSS et JavaScript.

## Consulter le site

Ouvrir `files/index.html` dans un navigateur.

- Accueil : `files/index.html`
- À propos : `files/Apropos.html`
- Inscription : `files/inscription.html`
- Contact : `files/contact.html`

Les emails sont vérifiés pendant la saisie. Les champs obligatoires et les emails invalides bloquent la soumission. Les formulaires sont une démonstration sans envoi de données.

Le menu est vertical sur mobile et tablette, puis horizontal dès 1024 px.

## Branches

- `main` : version finale du projet.
- `feature/formulaire` : développement des pages et des formulaires, fusionné via pull request.
- `livrable-b2` : documentation du livrable B2.
